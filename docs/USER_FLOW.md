# SGYUN Portfolio — User Flow

## 주요 경로

1. 사용자가 홈에 진입한다.
2. 다이얼, 스크롤, 키보드로 프로젝트를 바꾼다.
3. 프리뷰에서 작품 전체와 제목·유형을 확인한다.
4. `Open project` 또는 작품 목록을 통해 상세로 이동한다.
5. 상세에서 프리뷰, 전제, 챕터형 스토리를 읽는다.
6. 다음 프로젝트 또는 작품 목록으로 계속 탐색한다.
7. route dial의 `FIELD_00`을 발견하면 캘리브레이션 페이지에서 세 개의 목표 detent를 순서대로 맞추고 장치 잠금 해제 상태를 확인한다.

## 다이얼 입력 흐름

- 모바일의 홈·내부 페이지: 보이는 다이얼 면을 누르면 face가 확대된다. 12px 세로 의도 임계값을 넘긴 뒤 손가락 이동량에 가까운 저이득 page scrub이 시작되며, 손을 떼면 확대 상태와 강제 scroll override가 즉시 해제된다.
- 데스크톱의 홈·내부 페이지: 같은 page scrub을 마우스·펜 drag로 사용하고, wheel·trackpad·rail·키보드는 기존 탐색 경로를 유지한다.
- 일반 touch scroll·wheel·trackpad 스크롤은 입력 위치와 무관하게 passive scroll sync를 통해 다이얼 face와 현재 인덱스를 연속 갱신한다.
- `FIELD_00`: 페이지 스크롤과 분리된 전용 scrub 모드에서 touch·mouse drag, rail button, 방향키를 같은 숫자 입력으로 취급한다.
- gesture가 어려운 사용자는 rail button과 slider keyboard control로 동일한 완료 상태에 도달한다.

## VAULT_01 숨은 흐름

1. `FIELD_00`에서 `03 → 08 → 05`를 맞추면 `OPEN VAULT`가 나타난다.
2. 숨겨진 `/{lang}/vault`에서 `07 UP → 02 DOWN → 09 UP`을 다이얼 또는 `− / SET / +`로 입력한다.
3. 세 텀블러가 맞으면 aperture가 열리고 `RETURN TO ARCHIVE`와 `REPLAY`가 나타난다.
4. 완료 기록 없이 주소로 직접 접근하면 Calibration 복귀 링크만 표시한다. 이 상태는 게시·관리자 인증과 무관하다.

## 최초 방문 가이드

- Calibration을 제외한 첫 다이얼 화면에서만 반투명 2단계 가이드가 나타난다.
- 1단계는 일반 스크롤 동기화, 2단계는 다이얼 직접 drag를 설명하고 5초 안에 자동 종료한다. 닫기 버튼으로 즉시 종료할 수 있다.
- 노출 시 `localStorage`의 `sgyun:vault-dial-guide:v1`을 기록해 같은 브라우저에서는 랜딩으로 돌아와도 반복하지 않는다. 저장소 접근이 차단돼도 현재 mounted visit에서는 한 번만 보인다.

## 화면별 우선순위

- 홈: 작품 프리뷰 > 제목 > 탐색 상태 > 보조 설명
- 작품 목록: 스캔 가능한 작품 이미지·제목 > 필터 > 소개 문장
- 작품 상세: 전체 프리뷰 > 프로젝트 서사 > 메타데이터 > 다음 작품
- 모바일: 콘텐츠 가림 방지 > 엄지 접근성 > 촉각·소리 피드백

## 실패 조건

- 프리뷰에서 작품의 일부가 잘린다.
- 다이얼, 목차, 내비게이션이 작품 이미지 또는 핵심 텍스트를 가린다.
- 페이지 이동 시 같은 브랜드의 화면처럼 느껴지지 않는다.
- 장식 제거 후 더 좋아 보인다면 장식은 유지하지 않는다.
- 모바일 다이얼을 잡았을 때 페이지가 멈추거나 튀고, 손을 뗀 뒤 다른 섹션으로 과도하게 이동한다.
- 캘리브레이션이 정밀한 타이밍이나 숨겨진 gesture만 요구해 대체 입력으로 완료할 수 없다.
- 금고 조합이 숫자만 확인하고 방향을 무시하거나, 실패가 기존에 맞춘 텀블러까지 임의로 초기화한다.
