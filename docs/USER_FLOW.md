# SGYUN Portfolio — User Flow

## 주요 경로

1. 사용자가 홈에 진입한다.
2. 다이얼, 스크롤, 키보드로 프로젝트를 바꾼다.
3. 프리뷰에서 작품 전체와 제목·유형을 확인한다.
4. `Open project` 또는 작품 목록을 통해 상세로 이동한다.
5. 상세에서 프리뷰, 전제, 챕터형 스토리를 읽는다.
6. 다음 프로젝트 또는 작품 목록으로 계속 탐색한다.
7. route dial의 `FIELD_00`을 발견하면 캘리브레이션 페이지에서 세 개의 목표 detent를 순서대로 맞추고 장치 잠금 해제 상태를 확인한다.

## 다이얼 입력 흐름

- 모바일의 홈·내부 페이지: 다이얼 위 세로 드래그는 브라우저의 native scroll로 통과시키고, 스크롤 위치가 다이얼 face와 인덱스를 갱신한다.
- 데스크톱의 홈·내부 페이지: 다이얼을 직접 드래그하거나 wheel·rail·키보드로 섹션을 이동한다.
- `FIELD_00`: 페이지 스크롤과 분리된 전용 scrub 모드에서 touch·mouse drag, rail button, 방향키를 같은 숫자 입력으로 취급한다.
- gesture가 어려운 사용자는 rail button과 slider keyboard control로 동일한 완료 상태에 도달한다.

## 화면별 우선순위

- 홈: 작품 프리뷰 > 제목 > 탐색 상태 > 보조 설명
- 작품 목록: 스캔 가능한 작품 이미지·제목 > 필터 > 소개 문장
- 작품 상세: 전체 프리뷰 > 프로젝트 서사 > 메타데이터 > 다음 작품
- 모바일: 콘텐츠 가림 방지 > 엄지 접근성 > 촉각·소리 피드백

## 실패 조건

- 프리뷰에서 작품의 일부가 잘린다.
- 다이얼, 목차, 내비게이션이 작품 이미지 또는 핵심 텍스트를 가린다.
- 페이지 이동 시 같은 브랜드의 화면처럼 느껴지지 않는다.
- 장식 제거 후 더 좋아 보인다면 장식은 유지하지 않는다.
- 모바일 다이얼을 잡았을 때 페이지가 멈추거나 튀고, 손을 뗀 뒤 다른 섹션으로 과도하게 이동한다.
- 캘리브레이션이 정밀한 타이밍이나 숨겨진 gesture만 요구해 대체 입력으로 완료할 수 없다.
