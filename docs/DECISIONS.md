# SGYUN Portfolio — Design Decisions

## Primary preview는 작품을 자르지 않는다

대표 프리뷰의 역할은 분위기용 배경이 아니라 작품 감상이다. 단, 고정된 큰 상자에 `contain`만 적용하면 작품 주변에 거대한 letterbox가 생긴다. 따라서 이미지 데이터를 종횡비까지 포함하도록 확장하고, 프레임이 원본 비율을 따라가게 한다. `contain`은 안전장치로 유지하되 내부 패딩은 제거한다.

작품 주변의 여백은 이미지 상자 내부가 아니라 페이지 레이아웃에 둔다. 작은 dialog 썸네일과 folder background만 슬롯을 채우기 위한 의도적 crop을 허용한다.

## Slim Poppins를 브랜드 리듬으로 사용한다

Poppins의 기하학은 유지하되 큰 제목은 200–300으로 낮춘다. 한글과 설명은 Pretendard를 사용해 가독성을 유지한다.

## 라틴과 한글은 크기가 아니라 호흡을 분리한다

Poppins의 압축 자간과 짧은 행간을 Pretendard 한글에 그대로 적용하면 음절 블록 사이가 뭉치고 줄바꿈이 답답해진다. 영문 작품명과 대형 인덱스는 기존의 좁은 Poppins 리듬을 유지하되, 한글 선언문·premise·story·About 소개문은 별도의 완화된 자간과 1.04 이상의 행간을 사용한다. 설명문은 페이지별 임의 크기 대신 공통 body 토큰으로 통일하고, 마이크로그래픽의 작은 수치와 실제 읽기 문장을 구분한다.

## 재료감은 미디어에 집중한다

작품을 담는 미디어 프레임은 원본 비율의 큰 면과 얇은 aperture, 넓은 바깥 그림자에 집중한다. 필터·버튼·내비게이션은 낮은 반경과 얇은 상태 변화로 정리한다.

## 모호한 glass 대신 기계식 aperture를 사용한다

반투명 배경, blur, 여러 겹의 밝은 테두리를 동시에 사용했지만 실제 배경 굴절이나 명확한 광학 깊이가 없어 liquid glass가 아니라 평범한 패널처럼 보였다. 홈 primary media의 두꺼운 테두리와 광택 overlay를 제거하고, 원본 비율의 큰 이미지와 얇은 기계식 aperture, 바깥쪽 telemetry만 남긴다. 내비게이션과 홈 상단 도구도 folder field와 같은 solid graphite 계열로 통일한다.

## Vault dial을 장식이 아닌 전역 문법으로 확장한다

큰 오른쪽 다이얼은 홈의 프로젝트 탐색이라는 실제 입력을 담당한다. 내부 페이지와 보조 행동에는 큰 원을 반복하지 않고, 고정 datum·회전 latch·번호·비율 표기로 축소한다. `프로젝트 열기`는 일반 흰색 pill 대신 rotary latch가 있는 control plate가 되고, 전역 내비게이션의 SGYUN mark는 현재 route를 표시하는 작은 dial을 가진다.

## 마이크로그래픽은 실제 메타데이터만 표시한다

Figma Community의 Micrographics Templates에서 채택한 것은 작은 타이포 자체가 아니라 선의 종점, 좌표축, 번호, 비율, 상태를 한 기준선에 묶는 방식이다. SGYUN 구현에서는 프로젝트 번호, media aspect ratio, record count, route state처럼 검증 가능한 값만 사용한다. 의미 없는 인증 번호, 장식 아이콘, 가짜 기술 사양은 만들지 않는다.

큰 dial 옆의 `15°` 표기는 입력을 이해하는 데 필요하지 않아 제거했다. 이후 검토에서 실제 활성 번호와 어긋나던 독립 백색 emissive bar도 제거했다. 새 기준 그래픽은 검은 방사형 face 안에 포함된 비발광 bone-white capsule을 datum으로 사용한다. 메인 half dial에서는 활성 번호 축과 일치하고, 작은 latch에서는 face와 함께 회전한다. 현재 프로젝트는 다이얼 번호와 레일 타이포그래피의 명도·무게를 주상태로 사용하며, cobalt는 focus처럼 접근성상 분명한 시스템 상태에만 남긴다.

## 다이얼과 레일은 하나의 정수 인덱스를 공유한다

초기 marker 기준각이 `24°`로 고정돼 active rail이 `06`이어도 dial의 기준 위치에는 다른 번호가 걸렸다. marker 기준각을 왼쪽 중앙 `-90°`로 바꾸고 dial 회전값을 counter-rotation에 포함해 활성 번호가 항상 수평으로 읽히게 했다. ScrollTrigger는 손을 놓거나 스크롤이 멈춘 뒤 가장 가까운 `1 / (projectCount - 1)` 지점으로 snap하므로 rail, dial, scroll progress가 같은 정수 index에 정착한다.

## 사운드는 기능 상태가 아니라 기본 물성이다

`SOUND START`, `ON`, `OFF`는 포트폴리오 탐색에 필요한 선택이 아니며 상단 chrome만 늘렸다. sound control과 저장 preference를 제거하고 라쳇을 기본 활성화했다. Web Audio autoplay 정책상 첫 pointer·keyboard·touch 입력에서 context를 unlock하며, 이후 detent가 바뀔 때만 짧은 ratchet tick을 재생한다.

## 프로젝트 진입은 Vault가 닫히고 열리는 상태 변화다

프로젝트 CTA를 누르면 좌우 graphite shutter가 닫히고 중앙 rotary lock이 결합된 뒤 route가 바뀐다. 새 페이지에서는 같은 shutter가 반대 방향으로 열린다. transition은 페이지 전환을 숨기는 장식이 아니라 archive record가 잠겼다가 다음 기록에서 열리는 물리적 관계를 설명한다.

## 실제 데이터도 중복되면 장식으로 간주한다

홈 media 주변의 `VAULT_VIEW`, 하단 category axis, 상세 이미지 안의 중복 프로젝트 번호는 각각 실제 상태와 연결돼 있었지만 제목·레일·상단 정보와 같은 내용을 반복했다. micrographics는 홈 media 상단의 프로젝트 번호·제목·원본 비율 한 줄만 남기고 나머지는 제거한다. 정밀함은 표식 수가 아니라 정보의 선택과 정렬에서 만든다.

## CTA는 패널이 아니라 잠금장치로 읽혀야 한다

rotary latch를 사각 graphite 카드 안에 넣자 다이얼의 축소판보다 작은 대시보드 위젯처럼 보였다. CTA는 배경·외곽 shadow를 제거하고 래치, 문구, 한 개의 datum rail만 남긴다. hover/focus에서는 래치 회전과 rail의 비발광 백색 종점 확장이 같은 open 상태를 설명한다.

## dark-tech glow 대신 중성 반사광을 사용한다

푸른 대형 radial glow는 작품과 무관하게 generic AI·dark-tech 분위기를 만들었다. 코발트는 focus와 활성 각인 번호에만 유지하고, 장면의 큰 광원은 저채도 silver-grey 반사광으로 바꾼다.

## 필터는 버튼 묶음보다 하나의 선택 레일로 구성한다

INDEX의 유형 필터는 다섯 개의 사각 버튼을 반복하지 않는다. 하나의 baseline 위에 모든 유형과 실제 개수를 놓고, 현재 항목만 짧은 하단 datum으로 표시한다. 모바일에서는 같은 레일을 줄바꿈하지 않고 가로 탐색으로 유지한다.

## 페이지 내부의 테마 반전을 줄인다

홈과 상세는 연속된 graphite 계열, 작품 목록은 연속된 silver 계열을 사용한다. 섹션 전환은 큰 색상 반전보다 간격과 표면 단계로 구분한다.

## 반응형은 축소가 아니라 재구성이다

4열 데스크톱 구성을 768px까지 억지로 줄이지 않는다. 900px 이하에서는 미디어를 상단 전체 폭으로 이동하고, 정보와 오른쪽 다이얼을 별도 행으로 분리한다. 대형 선언문은 고정 `nowrap`을 금지하고 이미지와 문장을 grid로 배치해 우측 안전 여백을 확보한다.

## 미디어 프레임은 두 축의 제한을 동시에 계산한다

`width: 100%`와 `max-height`를 함께 쓰면 세로 작품의 프레임 비율이 깨진다. 홈과 상세의 제한된 미디어 슬롯은 size container가 되고, 프레임 너비는 `min(100cqw, 100cqh × 원본 비율)`로 계산한다. 작품을 바꿀 때마다 프레임 자체가 원본 비율로 변하므로 `contain`이 검은 여백을 만드는 상황을 예방한다.

## 반응형 위치 transform과 진입 모션을 분리한다

오른쪽 다이얼의 `translate(50%)`는 화면 크기에 따라 다시 계산되어야 한다. GSAP가 같은 요소의 x축을 애니메이션하면 최초 데스크톱 픽셀값으로 고정될 수 있으므로, 다이얼 진입은 opacity만 사용하고 위치 transform은 CSS가 독점한다.

## 작은 표식과 터치 영역은 분리한다

프로젝트 레일의 점은 시각적으로 3px 두께를 유지하지만 버튼 상자는 44px 높이를 가진다. 정밀한 계기판 인상과 모바일 조작성 중 하나를 희생하지 않는다.

## 상세 메타데이터는 작품 정체성에 귀속한다

상세 hero의 연도·분야·형식·archive 번호를 화면 최하단 전체 폭으로 펼치자 제목·이미지와 별개의 세 번째 장면처럼 분리됐다. 사양을 제목과 설명 아래 2×2 정보군으로 옮겨 작품 정체성의 일부로 묶는다. 넓은 negative space는 관련 정보군의 경계가 먼저 명확할 때만 고급스럽게 읽힌다.

한국어 설명에는 단어 단위 줄바꿈과 균형 줄바꿈을 적용해 의미 단위가 한두 글자만 다음 줄로 밀리는 고아줄을 막는다. 로컬 시각 검토에서는 Next.js 개발 표시도 끈다. 배포 요소가 아니더라도 검토 화면에서 콘텐츠를 덮으면 오버레이 회귀를 놓치게 만들기 때문이다.

## Rotary family는 하나의 face anatomy를 공유한다

내비게이션 route dial, 프로젝트 CTA, INDEX 기록 latch, folder action, 상세 next latch, route transition lock이 각각 다른 눈금 간격·중앙 허브·datum 위치를 사용하면서 사이트 전역이 같은 제품군으로 보이지 않았다. 사용자가 제시한 기준 그래픽에 맞춰 검은 산화금속 face, 촘촘한 방사형 spoke, 작은 recessed core, 우상단 bone-white capsule을 공통 해부로 고정한다. 큰 홈 다이얼만 프로젝트 번호와 활성 축을 추가하며, datum은 왼쪽 활성 번호 축에 정확히 붙인다.

## 작품보다 다이얼이 먼저 보이면 다이얼을 줄인다

오른쪽 half dial은 브랜드의 시그니처지만 작품보다 큰 시각 질량이 되면 탐색 장치가 주인공을 빼앗는다. 데스크톱 최대 지름을 380px로 낮추고 화면에는 절반만 노출한다. 레일·미디어·정보와의 전용 열은 유지해 축소를 다른 콘텐츠 확장의 근거로 사용한다.

## 긴 프로젝트명은 editorial overlap의 예외가 아니다

`RECOGNITION LOG`처럼 긴 단일 단어가 정보 열을 넘어 미디어 위에 놓이는 현상은 의도적 연출이 아니라 반응형 실패다. 가장 긴 단어 길이를 기준으로 compact optical scale을 적용하고 제목 열의 너비 안에서만 조판한다. 작품명과 primary media의 bounding box 교차 허용치는 0이다.

## 작업 원칙 장면은 정상 흐름으로 재구성한다

이미지를 한글 대형 제목의 line box 안에 끼우고 마지막 단어를 우측으로 밀어낸 구성은 문장과 미디어의 소유 관계가 모호했다. 해당 장면은 선언문과 미디어를 독립된 2열로 분리하고, CTA는 미디어 아래의 별도 행동 영역에 둔다. 장면의 품질은 겹침이 아니라 비율, 기준선, negative space로 만든다.
